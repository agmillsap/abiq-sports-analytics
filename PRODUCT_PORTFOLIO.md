## Featured independent product: ABIQ — Sports Decision Intelligence

**Product type:** Independent analytics and decision-support platform  
**Role:** End-to-end product builder and owner  
**Technologies:** Python, Streamlit, APIs, GitHub Actions, automated cloud workflows, HTML/CSS

**Problem.** Sports fans and fantasy players often have to reconcile projections, schedules, uncertainty, and scenario choices across multiple disconnected sources.

**Product approach.** Designed a unified decision experience that translates predictive and scenario-model outputs into accessible user workflows. Built and iterated navigation, forecasting surfaces, and a what-if planning prototype, while keeping model validation and production operations separated from the public demonstration.

**Product-management evidence.**
- Framed the problem and defined user-facing decision workflows.
- Iterated prototypes from user needs and feedback through interface design, automated refresh, testing, and deployment.
- Designed explainable views that make scenario trade-offs legible, rather than merely reporting a score.
- Maintained a public/private product boundary and documented limitations for illustrative data.

**Explore:** [ABIQ public showcase repository](https://github.com/agmillsap/abiq-sports-analytics) · [Live ABIQ experience](https://abiq-sports.streamlit.app)

## How I work

**Discover → Define → Prototype → Validate → Iterate.** Start with the user's decision and constraints; clarify the smallest useful workflow; define metrics and acceptance criteria; develop a working prototype; gather feedback; and refine the experience toward a repeatable, trusted process.

**Tools and methods:** SQL, Python, Salesforce CRM, Excel, Power BI, Anaplan, Streamlit, APIs, GitHub Actions, machine-learning-informed analytics, stakeholder interviews, requirements translation, and interactive prototyping.
