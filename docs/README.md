# Abigail Millsap · Interactive Product Portfolio

The complete original single-file portfolio supplied by the author is preserved across 14 fixed-size binary chunks in `parts/`, with `index.html` reassembling it in the browser. This avoids connector payload-size limits while preserving the embedded field-sales and market-opportunity interactive demos, case studies, and ABIQ link.

**Page content:** Field Sales Portfolio Optimization · Market Opportunity Navigator · ABIQ Sports Decision Intelligence.

**Publishing:** In GitHub, navigate to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/docs`, then click Save. Once GitHub confirms deployment, the site address will be listed in Pages settings.

**Privacy:** Enterprise product demos are explicitly marked as sample data within the portfolio; no private ABIQ source repository is exposed. Review employer branding and any future replacements before publishing.
